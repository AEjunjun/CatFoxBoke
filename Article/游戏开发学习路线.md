## 为什么想做游戏开发

从小就喜欢玩游戏，慢慢从「玩游戏」变成了「想自己做游戏」。虽然这条路很长，但每次看到自己写的代码在屏幕上跑起来，那种成就感无可替代。

## 我的学习路线

### 第一阶段：C# 基础（1-2 个月）

Unity 使用 C# 作为脚本语言，所以先打好语言基础很重要：

```csharp
// 面向对象基础
public class Player : MonoBehaviour
{
    public float speed = 5f;
    private int health = 100;

    void Update()
    {
        float h = Input.GetAxis("Horizontal");
        float v = Input.GetAxis("Vertical");
        transform.Translate(new Vector3(h, 0, v) * speed * Time.deltaTime);
    }

    public void TakeDamage(int damage)
    {
        health -= damage;
        if (health <= 0) Die();
    }
}
```

**核心概念：**

- 变量、类型、运算符
- 类与对象、继承、多态
- 集合（List、Dictionary）
- 委托与事件

### 第二阶段：Unity 入门（2-3 个月）

- Unity 编辑器界面熟悉
- GameObject 与 Component 模型
- Transform、物理引擎（Rigidbody、Collider）
- UI 系统（Canvas、Button、Text）
- 场景管理与加载

### 第三阶段：实战项目（持续）

做一个完整的 2D 小游戏，包含：

- 角色移动与跳跃
- 敌人 AI 基础
- 得分系统
- 简单的 UI 菜单

## 一些心得

### 不要一上来就追求大作

我刚开始学的时候想做一个开放世界 RPG……结果当然是放弃了。从小游戏开始，完成永远比完美重要。

### 美术和音乐可以先用免费资源

- OpenGameArt — 免费游戏素材
- Kenney — 高质量免费资源包
- Freesound — 免费音效

### 加入游戏开发社群

一个人的学习容易放弃，找到同好一起交流能极大提升动力。

## 写在最后
