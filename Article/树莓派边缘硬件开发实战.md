## 项目背景

这是参加职业院校技能竞赛的边缘计算赛道项目。硬件方案采用 **树莓派 4B + ADS1115 模数转换器**，配合土壤湿度传感器和继电器模块，实现了环境感知与自动灌溉的联动控制。

## 硬件清单

| 组件 | 型号/参数 | 作用 |
|------|-----------|------|
| 主控 | 树莓派 4B | 逻辑控制与数据处理 |
| ADC | ADS1115 (16-bit) | 模拟信号 → 数字信号 |
| 传感器 | 土壤湿度传感器 | 检测土壤含水率 |
| 执行器 | 双路继电器模块 | 水泵/阀门开关控制 |

## ADS1115 配置详解

ADS1115 是一款 16 位高精度 ADC，通过 I2C 与树莓派通信。关键配置参数：

```python
import board
import busio
import adafruit_ads1x15.ads1115 as ADS
from adafruit_ads1x15.analog_in import AnalogIn

# 初始化 I2C
i2c = busio.I2C(board.SCL, board.SDA)

# 创建 ADC 实例，PGA 设为 +/-6.144V（防止传感器输出溢出）
ads = ADS.ADS1115(i2c, gain=2/3)

# 读取 A1 通道（土壤湿度传感器接 A1）
chan = AnalogIn(ads, ADS.P1)
raw_value = chan.value  # 0 ~ 26400（16-bit 范围）
voltage = chan.voltage  # 实际电压值
```

### 为什么选 PGA ±6.144V？

土壤湿度传感器在干燥/湿润极端情况下输出电压可能超过标准 3.3V，使用 PGA ±6.144V 可以避免信号溢出导致的读数异常。

## 传感器校准

湿度传感器通过两个基准值进行线性映射：

```python
AIR_VALUE = 5000   # 完全干燥（空气中）的 ADC 读数
WATER_VALUE = 900  # 完全浸水时的 ADC 读数

def calc_humidity(raw):
    """将 ADC 原始值映射为 0-100% 湿度"""
    if raw >= AIR_VALUE:
        return 0.0
    if raw <= WATER_VALUE:
        return 100.0
    return (AIR_VALUE - raw) / (AIR_VALUE - WATER_VALUE) * 100
```

## 自适应平滑算法

ADC 读数存在随机噪声，直接使用原始值会导致继电器频繁误触发。我设计了一套 **加权滑动平均 + 动态异常值剔除** 的算法：

```python
from collections import deque

class SmoothSensor:
    def __init__(self, window_size=10, outlier_threshold=3.0):
        self.buffer = deque(maxlen=window_size)
        self.threshold = outlier_threshold

    def update(self, new_value):
        """返回平滑后的值"""
        if len(self.buffer) >= 3:
            avg = sum(self.buffer) / len(self.buffer)
            if abs(new_value - avg) > self.threshold * 50:
                return avg  # 异常值，用均值替代
        self.buffer.append(new_value)
        return sum(self.buffer) / len(self.buffer)
```

GPIO.setup(IN1, GPIO.OUT, initial=GPIO.HIGH)  # 高电平 = 关闭（低电平触发）
GPIO.setup(IN2, GPIO.OUT, initial=GPIO.HIGH)

## MQTT 数据上报

将传感器数据实时推送到云端：

```python
import paho.mqtt.client as mqtt

client = mqtt.Client()
client.connect("broker.emqx.io", 1883, 60)

# 上报格式：ADC:5000 湿度:25.3%
topic = "sensor/soil"
payload = f"ADC:{raw_value} 湿度:{humidity:.1f}%"
client.publish(topic, payload)
```
